# Overview

OntDekker is a community-first slow-travel platform designed to replace traditional tourism with meaningful local experiences.

Instead of focusing on hotel bookings and viral travel content, OntDekker helps travelers:

- Discover authentic places
- Connect directly with verified local guides
- Plan expeditions collaboratively
- Optimize packing and logistics
- Build long-term travel relationships

---

# Product Vision

Build the world's most elegant slow-travel platform where travelers replace rushed tourism with immersive, community-led experiences guided by trusted local experts.

---

# Product Mission

Encourage slower, more meaningful travel by replacing checklist tourism with authentic human connections while empowering local communities through direct traveler engagement.

# Navigation & User Flow

| User Action | Location | Result | Purpose |
|-------------|----------|--------|---------|
| Click Story Card | Discover Feed | Opens immersive fullscreen story modal | Maintain browsing context |
| Open Guides | Sidebar | Opens Guide Portal | Dedicated guide discovery |
| View Guide Profile | Guide Directory | Opens Guide Portfolio | Increase booking confidence |
| Invite Guide | Guide Profile | Opens Expedition Matcher | Reduce booking friction |
| Reconnect Guide | My Guides | Opens private conversation | Encourage repeat trips |
| Open Expedition | My Trips | Opens planning workspace | Centralized collaboration |
